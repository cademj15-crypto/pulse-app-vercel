# Mobile-ready update

This version is optimized for phones as a responsive web app/PWA.

Changes include:
- device-width viewport and safe-area support for iPhone notches / Dynamic Island
- phone-sized score rings and metric cards
- sticky compact top navigation
- 44px+ touch targets
- bottom-sheet style detail/settings modals on phones
- responsive 2-column metric grid (1 column on very small screens)
- standalone web-app metadata and `manifest.webmanifest`
- Apple web-app metadata so it can be added to the iPhone Home Screen

Once hosted on HTTPS, open the site in Safari on iPhone and use Share > Add to Home Screen to launch it like an app.
