# Pulse

Mobile-first recovery, sleep, and strain dashboard built with Next.js.

## Run locally

```bash
npm install
npm run dev
```

## Deploy to Vercel

This project now uses the standard Next.js commands expected by Vercel:

```bash
npm run build
npm start
```

See `VERCEL-DEPLOY.md` for deployment notes and `SETUP.md` for connected health-data setup.
